### P0-2：实现 OCR 服务

新建目录 `ocr_service/`（项目根），独立 FastAPI 进程，GPU 运行 Unlimited-OCR。

**目录**：

```
ocr_service/
  server.py          # FastAPI :10001  POST /ocr
  model.py           # OCRModel 封装
  requirements.txt
```

**`ocr_service/model.py`**（核心）：

```python
import torch, tempfile
from transformers import AutoModel, AutoTokenizer

MODEL_PATH = r"<MODELS_DIR>\Unlimited-OCR"

class OCRModel:
    def __init__(self):
        self.tok = AutoTokenizer.from_pretrained(MODEL_PATH, trust_remote_code=True)
        self.model = AutoModel.from_pretrained(
            MODEL_PATH, trust_remote_code=True,
            use_safetensors=True, torch_dtype=torch.bfloat16,
        ).eval().cuda()

    def infer(self, image_path: str) -> str:
        r = self.model.infer(
            self.tok, prompt="<image>document parsing.",
            image_file=image_path, output_path=tempfile.mkdtemp(),
            base_size=1024, image_size=640, crop_mode=True,
            max_length=32768, no_repeat_ngram_size=35, ngram_window=128,
            save_results=False,
        )
        return r if isinstance(r, str) else ""
```

**`ocr_service/server.py`**：

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from pathlib import Path
from .model import OCRModel

app = FastAPI()
_m: OCRModel | None = None

@app.on_event("startup")
async def _load(): global _m; _m = OCRModel()

@app.post("/ocr")
async def ocr(req: BaseModel):   # image_path: str
    if not _m: raise HTTPException(503)
    if not Path(req.image_path).exists(): raise HTTPException(400, "File not found")
    return {"text": _m.infer(req.image_path)}
```

**`backend/app/services/ocr_client.py`**（新增）：

```python
import httpx, tempfile
import fitz
from ..config import settings

async def ocr_pdf_page(page: fitz.Page) -> str:
    if not settings.OCR_API_URL:
        return ""
    with tempfile.NamedTemporaryFile(suffix=".png", delete=False) as tmp:
        page.get_pixmap(matrix=fitz.Matrix(300/72, 300/72)).save(tmp.name)
        async with httpx.AsyncClient(timeout=120) as c:
            r = await c.post(f"{settings.OCR_API_URL}/ocr", json={"image_path": tmp.name})
            r.raise_for_status()
            return r.json().get("text", "")
```

### P0-3：支持 txt / docx

在 `parse_service.py` 的 `handlers` 字典追加两个 handler：

```python
# handlers 中新增
"txt": _parse_txt,
"docx": _parse_docx,
```

```python
async def _parse_txt(path: Path, job: dict) -> dict:
    text = path.read_text(encoding="utf-8", errors="replace")
    options = _job_options(job)
    title, content_hash = await _resolve_doc_meta(text, job, path)
    chunks = await _build_text_chunks(text, title, options)
    return {
        "document": {"title": title, "doc_type": job.get("doc_type", "text"),
                     "business_domain": job.get("business_domain", "general"),
                     "source_uri": str(path), "content_hash": content_hash},
        "pages": [{"page_number": 1, "text": text}], "chunks": chunks,
        "data_assets": [], "sheets": [], "errors": [],
        "stats": {"pages": 1, "chunks": len(chunks), "data_assets": 0, "sheets": 0, "errors": 0},
    }

async def _parse_docx(path: Path, job: dict) -> dict:
    from docx import Document as DocxDocument
    doc = DocxDocument(path)
    text = "\n\n".join(p.text for p in doc.paragraphs if p.text.strip())
    options = _job_options(job)
    title, content_hash = await _resolve_doc_meta(text, job, path)
    chunks = await _build_text_chunks(text, title, options)
    return {
        "document": {"title": title, "doc_type": job.get("doc_type", "document"),
                     "business_domain": job.get("business_domain", "general"),
                     "source_uri": str(path), "content_hash": content_hash},
        "pages": [{"page_number": 1, "text": text}], "chunks": chunks,
        "data_assets": [], "sheets": [], "errors": [],
        "stats": {"pages": 1, "chunks": len(chunks), "data_assets": 0, "sheets": 0, "errors": 0},
    }
```

### P1-2：真实 Embedding 支持

**问题**：`_mock_embed` 是随机向量，向量检索完全无意义。

**方案**：在 `config.py` 增加 `EMBEDDING_API_URL` / `EMBEDDING_MODEL`，实现 `RealEmbeddingService`，接口与 `MockEmbeddingService` 相同（`async embed(text) -> list[float]`）。

`db_writer.py` 已支持 `embedding_model` 参数，只需：

```python
# config.py
EMBEDDING_API_URL: str = ""     # 空 = 用 mock
EMBEDDING_MODEL: str = "text-embedding-3-small"

# core/embedding.py 新增
class RealEmbeddingService:
    async def embed(self, text: str) -> list[float]:
        async with httpx.AsyncClient() as c:
            r = await c.post(f"{settings.EMBEDDING_API_URL}/embeddings",
                             json={"input": text, "model": settings.EMBEDDING_MODEL},
                             headers={"Authorization": f"Bearer {settings.LLM_API_KEY}"})
            return r.json()["data"][0]["embedding"]
```

`db_writer._mock_embed` 替换为调用全局 embedding service 实例。

MAX_UPLOAD_BYTES = 50 * 1024 * 1024  # 50MB

@router.post("/ingestion/uploads")

### P1-4：预览文件自动清理

**问题**：`output/ingestion/` 下预览 JSON 永久积累。

**方案**：在 `ingestion_service.py` 的 `_run_commit` 成功写库后删除预览文件；另在 `IngestionService` 启动时扫描并删除超过 7 天的旧文件。

```python
# _run_commit 成功后
import os
try:
    os.unlink(preview_path)
except OSError:
    pass

# IngestionService.__init__ 追加
self._cleanup_old_previews(max_age_days=7)

def _cleanup_old_previews(self, max_age_days: int):
    import time
    cutoff = time.time() - max_age_days * 86400
    for f in self.output_dir.glob("*_preview.json"):
        if f.stat().st_mtime < cutoff:
            f.unlink(missing_ok=True)
```

## 四、P2：功能扩展

### P2-1：LLM 富化解耦 langchain

**问题**：`llm_enrich.py` 通过 `import langchain_openai` 判断是否可用，包未装则完全禁用。

**方案**：改为直接用 `httpx` 调用 OpenAI 兼容 API，只依赖 `LLM_API_KEY`：

```python
def is_available() -> bool:
    return bool(os.getenv("LLM_API_KEY", ""))

async def _call_llm(prompt: str) -> str:
    async with httpx.AsyncClient(timeout=60) as c:
        r = await c.post(
            f"{os.getenv('LLM_BASE_URL', 'http://localhost:3000/v1')}/chat/completions",
            headers={"Authorization": f"Bearer {os.getenv('LLM_API_KEY')}"},
            json={"model": os.getenv("LLM_MODEL", "gpt-4o-mini"),
                  "messages": [{"role": "user", "content": prompt}],
                  "response_format": {"type": "json_object"}},
        )
        return r.json()["choices"][0]["message"]["content"]
```

### P2-2：进度细粒度更新

**问题**：大文件（500 chunks）写库阶段进度固定跳到 100，用户不知道是否卡住。

**方案**：`_write_to_db` 每写完 50 个 chunk 更新一次进度：

```python
total = len(chunks)
for i, chunk_batch in enumerate(batched(chunks, 50)):
    await write_batch(...)
    pct = 80 + int(i / max(total // 50, 1) * 20)
    await self.job_store.update_status(job_id, progress=pct)
```

### P2-3：Excel 通用模式

**问题**：`ExcelLoader` 只读 `tables/columns/metrics/cases/tools` 五个 sheet 名，普通业务 Excel 完全忽略。

**方案**：`JobRequest.options` 增加 `excel_mode: "data_asset"(现有) | "text"(新)`。

`excel_mode=text` 时：逐 sheet 把表格转为 Markdown 表格文字，走 `_build_text_chunks` 分块入库：

```python
async def _parse_excel(path: Path, job: dict) -> dict:
    options = _job_options(job)
    excel_mode = options.get("excel_mode", "data_asset")
    if excel_mode == "text":
        return await _parse_excel_as_text(path, job)
    # 原有 data_asset 逻辑不变
    ...

async def _parse_excel_as_text(path: Path, job: dict) -> dict:
    import pandas as pd
    sheets_text = []
    for name in pd.ExcelFile(path).sheet_names:
        df = pd.read_excel(path, sheet_name=name).fillna("")
        sheets_text.append(f"## {name}\n\n{df.to_markdown(index=False)}")
    text = "\n\n".join(sheets_text)
    title, content_hash = await _resolve_doc_meta(text, job, path)
    chunks = await _build_text_chunks(text, title, _job_options(job))
    return {"document": {...}, "chunks": chunks, ...}
```

### P2-4：支持 pptx

```python
"pptx": _parse_pptx,

async def _parse_pptx(path: Path, job: dict) -> dict:
    from pptx import Presentation
    prs = Presentation(path)
    slides = []
    for i, slide in enumerate(prs.slides, 1):
        texts = [shape.text_frame.text for shape in slide.shapes if shape.has_text_frame]
        slides.append(f"## 第{i}页\n\n" + "\n".join(t for t in texts if t.strip()))
    text = "\n\n".join(slides)
    title, content_hash = await _resolve_doc_meta(text, job, path)
    chunks = await _build_text_chunks(text, title, _job_options(job))
    return {"document": {...}, "chunks": chunks, ...}
```

## 五、P3：长期优化

### P3-1：接入解析库统一

`ingestion/app/loaders/MarkdownLoader` 与 `parse_service._parse_markdown` 是两套独立实现。长期应让 `parse_service` 调用 `ingestion/` 中的 Loader，消除重复。

### P3-2：后台任务持久化

当前 `asyncio.create_task` 在服务重启后任务丢失。改用独立 Worker 进程（Celery / ARQ / 简单轮询 DB 队列）实现任务持久化，支持重启恢复。

### P3-3：SSE 实时进度

`GET /ingestion/jobs/{id}` 改为 Server-Sent Events，客户端无需轮询，大文件写库进度实时推送。

### P3-4：批量 / URL 接入

- `POST /ingestion/batch`：接受文件列表，并行创建多个 job
- `POST /ingestion/url`：传入 URL，后端 fetch HTML → 转 Markdown → 走现有链路
