## 一、目标拆解

**最终交付物**（求职时拿得出手的）：
- 2-3 个完整可演示的 AI 应用项目（GitHub + 在线 Demo）
- 一份能讲清楚技术选型和踩坑过程的简历
- 能在面试中现场写代码、解释 Agent / RAG 工作机制

**对应能力锚点**：
1. Python 工程化够用：能写清晰的模块、会调试、会用常用库
2. LLM API 熟练：OpenAI / Claude / 国内模型至少各用过一个
3. Prompt 工程：能拆解需求、设计 Prompt、做评测
4. Agent 框架：至少深入一个（LangChain / LlamaIndex / 自研）
5. RAG 系统：从切分、向量化、检索、重排、生成全链路独立搭建过
6. 工作流编排：用过 Dify / n8n / Coze 之类，理解多 Agent 协作
7. 部署：会用 FastAPI 包装、会上 Docker、会接前端

## 二、阶段划分（按 6 个月预留缓冲，目标 3 个月即可面试）

### 阶段一：Python 补强 + Prompt 入门（第 1-3 周）
**目标**：补齐 Python 实战短板，同时启动 Prompt 工程，让"写代码的手感"和"调 LLM 的手感"同步建立。

- Python：函数 / OOP / 文件 IO / 异常 / 标准库 / requests / pydantic / 调试与日志
- Prompt：基本结构、Few-shot、CoT、Role 设定、输出格式控制、评测方法
- 工具：Git 基础、VSCode、虚拟环境、pip / uv

**验收**：写 3-5 个 Python 小工具 + 1 个能跑通的 LLM 调用脚本（含 Prompt 评测）

### 阶段二：LLM API + 第一个 Agent 项目（第 4-6 周）
**目标**：从"调 API"升级到"组装 Agent"，产出第一个作品集项目。

- LLM API 深入：流式、function call / tool use、JSON 模式、token 管理
- Agent 基础：ReAct 模式、Tool 设计、记忆机制、错误处理
- 框架二选一：LangChain 或 自研最小 Agent（推荐先自研再看框架）

**验收**：项目 1 完成 —— 一个有实际用途的 Agent（如：文献整理助手 / 个人日报生成器 / 代码 Review 助手）

### 阶段三：RAG 系统全链路（第 7-9 周）
**目标**：搞透 RAG，这是 AI 应用岗的核心面试点。

- 文档处理：切分策略、清洗、元数据
- 向量化：embedding 模型选型、向量数据库（Chroma / Qdrant / Milvus）
- 检索：相似度、混合检索、重排
- 生成：上下文压缩、引用溯源、幻觉控制
- 评测：召回率、答案准确率、人工评测

**验收**：项目 2 完成 —— 一个领域 RAG 应用（如：技术文档问答 / 个人知识库助手）

### 阶段四：工作流编排 + 综合项目（第 10-13 周）
**目标**：从单点能力升级到系统能力，做一个能打的简历项目。

- 工作流平台：Dify 或 n8n 实操
- 多 Agent 协作：路由、协作模式、状态管理
- FastAPI 包装、前端联调（用 Streamlit / Gradio 起步即可）
- Docker 部署、域名 + HTTPS、日志与监控

**验收**：项目 3 完成 —— 一个完整产品形态的 AI 应用，有前端、有部署、有用户能体验

### 阶段五：求职冲刺（第 14-20 周，弹性）
- 简历打磨（按项目讲故事，不堆技术名词）
- 八股梳理：LLM 原理够用版、Transformer 架构、常见 Prompt / RAG 题
- 面试模拟：自我介绍 / 项目讲解 / 现场写代码
- 投递节奏管理（小公司练手 → 中型目标公司 → 大厂）

## 三、防过载机制

10h/天非常容易在第 2-3 周崩盘。骨架内置三条规则：

1. **番茄工作法**：50 分钟 + 10 分钟休息，每 4 个番茄强制休息 30 分钟
2. **每日上限**：实际"专注学习"超过 8h 就停，剩余时间做复盘 / 回看 / 整理笔记
3. **每周一天浅学日**：周日只做总结、整理、轻量阅读，不啃硬骨头
