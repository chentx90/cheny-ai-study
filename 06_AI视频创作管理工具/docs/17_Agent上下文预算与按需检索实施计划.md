# Agent 上下文预算与按需检索实施计划

**状态**：已完成  
**日期**：2026-07-19  
**目标**：仅在预计输入达到模型上下文上限时压缩，并一次压到默认 20%；实体和大型工具结果改为轻量索引与按需读取。

## 1. 约束

1. 历史消息默认保持原文，不再按固定消息条数每轮压缩。
2. 压缩触发条件：`预计输入 Token + 输出预留 Token >= contextWindowTokens * compressionThreshold`。
3. 默认触发阈值为 80%，压缩后目标为上下文窗口的 20%。
4. 压缩只处理已完成的较早对话和可引用工具结果，保留最近消息及当前待确认操作。
5. 项目实时状态不写进历史摘要，始终从数据库重新读取。
6. 实体上下文只携带轻量索引；完整设定、证据、变体、提示词和任务通过工具按需查询。
7. 工具完整结果继续持久化到 `agent_tool_calls`，模型上下文只放摘要和安全引用。

## 2. 配置

`workflow_agent` 使用点新增：

- `contextWindowTokens`：模型上下文窗口，默认 `128000`。
- `reservedOutputTokens`：输出预留，默认 `12000`，保存时不超过上下文窗口的一半。
- `compressionThreshold`：触发比例，默认 `0.8`。
- `compressionTarget`：压缩目标，默认 `0.2`。
- `recentMessagesToKeep`：触发压缩后至少保留的近期消息数，默认 `8`。

`maxTokens` 继续只表示单次最大输出，不参与输入窗口定义。

## 3. Token 预算

在每次 ReAct 模型调用前组装完整提示词并估算输入 Token：

```text
模板规则 + 工具目录 + 项目轻量上下文 + 历史摘要 + 未压缩消息 + 本轮观察 + 用户请求
```

ASCII 按约 4 字符 1 Token、非 ASCII 按约 1 字符 1 Token 保守估算。达到阈值后，将最旧消息合并到持久摘要，直到预计输入本身降到目标值或只剩保留窗口。输出预留只参与触发安全线，不计入 20% 压缩目标。

## 4. 实体按需读取

项目上下文只发送：

```json
{"id":"eprof_xxx","name":"春潮香铺","type":"scene","has_setting":false,"has_asset_prompt":false,"image_status":null}
```

新增 `entity-profile.search`，按名称、别名和类型返回少量候选；命中后使用 `entity-profile.show` 获取完整详情。实体索引设置数量上限并返回 `index_truncated`，超出时强制搜索。

## 5. 大结果引用

超过内联上限的工具结果转换为：

```json
{
  "result_ref": "agent-result://<run_id>/<tool_call_id>",
  "summary": "读取 20 集剧本，共 58231 字",
  "chars": 58231
}
```

新增 `agent-result.read`，按引用、偏移和最大字符数读取持久化结果。引用必须校验 run、tool call 和当前项目的绑定关系，禁止跨项目访问。

## 6. 验收

1. 未达到 80% 时摘要和 `summary_message_id` 不变化。
2. 达到阈值后一次压到约 20%，近期消息保持原文。
3. 200 个实体不会携带完整设定预览；超过索引上限时可通过搜索定位。
4. 剧本等大型工具结果在后续步骤只携带引用和摘要，能够按需分段回读。
5. “春潮香铺”仍直接命中现有实体，不重新执行实体提取。
6. 后端全量、前端测试、生产构建和运行态冷重启通过。

## 7. 实施结果

- `workflow_agent` 的五项预算参数已支持后端归一化、用户级持久化和设置页编辑。
- 历史消息在未达到阈值时保持原文；触发后只压缩较早消息，摘要和边界消息 ID 持久化到会话。
- 项目上下文只携带最多 100 个实体的轻量索引，完整详情通过 `entity-profile.search` 和 `entity-profile.show` 按需读取。
- 超过 12000 字符的工具结果只进入摘要与 `result_ref`；`agent-result.read` 支持最多 12000 字符的分页回读，读取结果不会再次被包装成新引用。
- 桌面 Agent 栏保持默认展开；900px 以下首次默认折叠，并分别记忆桌面和窄屏偏好。
- 验证结果：后端 `90 passed`，Agent 专项 `12 passed`，前端 Vitest `4 passed`，生产构建通过；桌面 1440x900 与窄屏 390x844 无横向溢出。
- 本地后端 `http://127.0.0.1:8000` 与前端 `http://127.0.0.1:5173` 已冷重启，`AVM_AUTH_DISABLED=1`，未启动 Docker 或 SSH。
