## 正式生产链

```text
Project -> Document -> Episode(source_text + script_text)
-> PromptCard -> PromptCardEntityLink
-> VideoTask(request_snapshot) -> VideoOutput -> adopted
```

- `PromptCard` 是唯一分镜生产单元，不存在 Shot 业务模型或 `shot_ids`。
- 项目组合视图只读 `/session`；所有保存走类型化资源 API。
- `project_workspaces` 在启动迁移后删除，Episode 是原文和剧本唯一写入源。
- 项目素材按 SHA-256 去重；实体素材只保存稳定 ProjectAsset 引用。
- LLM 使用 LangChain/LangGraph 适配层，模板来自提示词管理，AI Run 不保存 thinking。
- 模板只播种可复制示例，支持 CRUD、版本历史和恢复为新版本。
- 视频任务先持久化再执行，启动恢复未完成任务；每次成功结果成为独立 VideoOutput 候选，可原子采用。

## 外部限制
