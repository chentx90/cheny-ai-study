# AI视频创作管理工具 - 项目概述

## 项目基本信息

**项目名称**: AI视频创作管理工具  
**项目类型**: 本地部署的视频生成流程管理平台  
**开发模式**: TDD + BDD驱动开发  
**目标用户**: 需要批量生成高质量AI视频的内容创作者

## 项目愿景

构建一个轻量级、本地化的AI视频创作管理平台，通过完整的流程管理和质量控制，将文本内容（剧本、小说、文案）高效转换为高质量视频。平台强调质量优先、流程可控、素材复用，适合需要精细控制的付费视频生成场景。

## 核心价值主张

### 1. 质量优先而非自动化
- 每个关键节点支持人工审核确认
- 付费生成场景下的成本控制
- 可选的快速预览功能降低试错成本

### 2. 流程完整可控
- 从文本到视频的完整工作流
- 支持从任意节点开始（前置信息足够时）
- 自动检查点保存，支持随时恢复

### 3. 本地化部署
- 所有数据存储在本地
- 实体库、提示词模板本地管理
- 支持离线工作模式

### 4. 素材复用与版本管理
- 实体卡片跨项目复用
- 提示词模板库管理
- 版本对比与回滚功能

## 核心功能模块

### 模块1: 文档处理引擎
**功能**: 接收各类文本格式，进行智能切分和剧本转换
- 支持格式: txt, md, doc, docx
- AI智能切分建议系统
- 多种切分策略（章节/时长/手动标记）
- 剧本格式转换与验证

### 模块2: 实体管理系统
**功能**: 管理角色、道具、场景等实体及其多状态变体
- 实体卡片系统（实体·状态）
- 多媒体素材组合（图片/声音/视频）
- 智能预绑定与模糊匹配
- 场景模板库支持

### 模块3: 提示词工程系统
**功能**: 管理和应用各类提示词模板
- 剧本转换提示词模板
- 实体提取提示词模板
- 视频生成提示词模板
- 风格推荐系统

### 模块4: 视频生成引擎
**功能**: 对接视频生成API，批量处理生成请求
- 视频生成助手Agent
- 快速预览功能（4秒试验片段）
- 批量处理支持
- CLI/API双模式调用

### 模块5: 配置与监控中心
**功能**: 统一管理API配置、流程监控、全局开关
- API配置管理（LLM/图片/视频）
- 流程预检系统
- 进度追踪面板
- 全局配置开关（质量优先/自动同意模式）

### 模块6: 版本与缓存管理
**功能**: 版本控制、检查点保存、素材复用
- 自动检查点系统（3个关键节点）
- 版本对比与回滚
- 素材复用库
- 批量操作面板

## 主工作流程

```
文本输入 → 文档处理 → 剧本转换 → 实体提取 → 实体绑定 
→ 提示词生成 → 文件确认 → [快速预览] → 视频生成 → 视频归档
```

**关键特性**:
- 任意节点可作为起点（前置信息足够时）
- 3个自动检查点（切分完成/剧本转换完成/实体绑定完成）
- 所有人工确认节点可通过全局开关控制
- 支持快速跳转到特定流程节点

## 技术架构原则

### 1. 本地优先 (Local-First)
- 核心数据存储在本地文件系统
- 仅视频生成调用外部API
- 离线模式下可完成大部分工作

### 2. 模块化设计
- 各功能模块低耦合
- 接口标准化，便于替换实现
- 支持插件式扩展

### 3. 测试驱动
- TDD: 单元测试先行
- BDD: 业务场景覆盖
- 集成测试保证端到端流程

### 4. 可观测性
- 完整的日志记录
- 流程状态追踪
- 性能指标监控

## 风险与挑战

### 技术风险
1. **外部API稳定性**: 依赖第三方视频生成API
   - 缓解措施: 支持多API源切换，本地队列缓冲
   
2. **大文件处理性能**: 长篇小说切分可能耗时
   - 缓解措施: 流式处理，增量保存

3. **实体匹配准确性**: AI提取可能误判
   - 缓解措施: 人工确认环节，相似度阈值可调

### 业务风险
1. **用户学习曲线**: 流程复杂度
   - 缓解措施: 详细文档，快速跳转功能

2. **成本控制**: 视频生成费用
   - 缓解措施: 快速预览，批量处理优化
