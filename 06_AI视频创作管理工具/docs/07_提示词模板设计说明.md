# 提示词模板设计说明

## 设计原则

提示词模板只负责把当前流程节点需要的输入组织成 LLM 请求，不负责改业务流程。整集生成、单卡重跑、主体匹配、视频请求整理必须使用不同模板分类，不能把其他节点的变量混进当前模板。

模板中的变量统一使用 `$变量名`。保存模板时系统会自动解析变量，并校验该分类的必需变量是否存在。示例模板以 `tpl_example_` 开头，是系统内置参考模板，建议复制后再改成项目自己的模板。

输出格式要写进模板正文，尤其是 JSON、分隔符、字段名、是否允许解释文本。凡是后端要解析的输出，都必须要求模型不要输出 Markdown、解释、推理过程或 thinking 内容。

## 分类与变量

| 分类 | 使用点 | 必需变量 | 说明 |
| --- | --- | --- | --- |
| `split_planning` | 按时长进行分集切分 | `$minutes`, `$content` | 让 LLM 根据目标分钟数和完整原文返回分集原文数组。 |
| `script_convert` | 原文转剧本 | `$content_type`, `$content` | 把小说、分集原文等转换为可继续生成视频提示词的剧本。 |
| `entity_extract` | 从剧本提取实体 | `$script` | 返回人物、场景、物品 JSON 数组。 |
| `image_prompt` | 实体参考图提示词 | `$entity` | 可额外使用 `$state`, `$style`，生成单个实体参考图提示词。 |
| `subject_match` | 提示词卡片匹配实体卡 | `$prompt_card`, `$entity_catalog` | 返回 `{"matches":[{"entity_card_id","reason"},...]}`（json_object 模式要求顶层对象）。 |
| `video_generate` | 本集剧本生成多张提示词卡片 | `$script`, `$entity_catalog`, `$expected_total_duration_seconds` | 只用于整集生成，不包含单卡重跑变量；LLM 输出多少张就入库多少张。 |
| `prompt_rerun` | 单张提示词卡片重跑 | `$script`, `$entity_catalog`, `$max_duration_seconds`, `$target_card`, `$generated_context` | 只用于重写一张目标卡片。 |
| `video_agent` | 视频生成请求整理 | `$segment`, `$prompt` | 根据片段和最终提示词整理请求参数建议。 |

## 变量详解

`$minutes`
按时长切分时的每集目标分钟数。它不是硬性字数限制，而是让模型判断剧情容量和切分颗粒度。

`$content`
当前待处理文本。用于切分时表示完整原文，用于剧本转换时表示当前集原文。

`$content_type`
输入文本类型，例如小说原文、分集原文、口播稿、已有剧本。它用于告诉模型应该按什么语境转换。

`$script`
当前集完整剧本。整集生成、实体提取、单卡重跑都以它作为剧情来源，不应自行扩写新剧情。

`$entity`
单个实体名称，例如人物名、场景名、物品名。主要用于实体参考图提示词。

`$state`
实体状态、造型、情绪或所处环境。不是所有分类必需，但图像提示词模板可以使用。

`$style`
项目视觉风格要求，例如现代纪实、古风写实、低饱和胶片感。不是所有分类必需。

`$prompt_card`
主体匹配时的当前提示词卡片，通常包含标题、原文摘录、提示词正文、已有锚定信息。

`$entity_catalog`
项目实体卡库。用于视频提示词生成和主体匹配，帮助模型保持人物、场景、物品一致。

`$max_duration_seconds`
单张提示词卡片建议最长视频时长，单位秒。当前主要用于单卡重跑和兼容旧模板；整集生成不再用它决定输出数量。

`$expected_total_duration_seconds`
整集生成时的本集预期总时长，单位秒。它只是给 LLM 判断节奏密度的参考，不是硬性数量限制；系统不会用它计算或校验目标卡片数量，即使估计不准，也不应导致生成失败。

`$target_card_count`
旧模板兼容变量，不再推荐使用。系统不会再估算或校验目标卡片数量，整集生成以 LLM 实际返回的卡片为准。

`$target_card`
单卡重跑的目标卡片，包含 ID、顺序、来源范围、原提示词等。它只能用于 `prompt_rerun`。

`$generated_context`
本集已生成提示词卡片上下文。单卡重跑用它保持前后衔接，不应用于整集生成模板。

`$segment`
视频生成请求整理时的当前分集或片段信息。

`$prompt`
已经确认的视频提示词正文，用于整理视频生成请求，不应再次改写剧情。

## 输出约束建议

分集切分返回 JSON 字符串数组。

实体提取返回 JSON 数组，元素建议包含 `name`、`type`、`state`、`tags`。

主体匹配返回 JSON 数组，元素建议包含 `entity_card_id` 和 `reason`，只能使用现有实体卡 ID。

整集提示词生成返回多张卡片，卡片之间用单独一行 `---` 分隔。每张卡片建议包含标题、时长、原文摘录、实体、提示词。不要在模板里写死数量，卡片数量由 LLM 根据剧本内容和预期总时长自行判断。

单卡重跑只返回一张卡片，必须围绕 `$target_card` 的来源范围重写，并参考 `$generated_context` 保持连续性。
