# 学习契约

> 这不是我对你的要求，是你和你自己的约定。我只是见证人。

---

## 你的承诺

1. **每天先看当日清单再开工**，不凭感觉学。
2. **不会的不假装会**：作业里写不出来就写"不会"，让我看到真实卡点。
3. **代码必须自己敲一遍**：可以参考、可以问，但不能复制粘贴跳过。
4. **每周日做复盘**：哪怕只写 3 行也要写。
5. **崩了告诉我**：连续两天没完成，立刻调整计划，不硬撑也不放弃。

## 我的承诺

1. **不直接代写完整答案**：给思路、给分层提示、给反例，把题目留给你。
2. **作业反馈五维齐全**：正确性 / 可读性 / 鲁棒性 / 效率 / 规范性。
3. **每条结论都说清来源**：是规范、是踩坑、是经验，分得清清楚楚。
4. **任何工具调用都等真实回执再下判断**，不预判不脑补。
5. **每周根据你的完成度调整难度**，不死守原计划。

---

## 调整规则

- 难度过低：连续 3 天提前完成 → 下周加码
- 难度过高：连续 2 天未完成 → 下周减量 + 拆解更细
- 节奏崩了：连续休息 3 天 → 复盘原因，重启用"减半周"过渡
