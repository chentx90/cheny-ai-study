## 已完成作品简报

### 日报摘要器
- 技术栈：Python / LangChain / OpenAI API / argparse
- 功能：CLI 工具，输入日报文字，输出 4 类结构化 JSON（完成/进行中/计划/风险）
- 亮点：支持流式输出 / 历史记录持久化 / --stream 参数

### Function Call 多工具 Agent
- 技术栈：Python / OpenAI Function Call / Ollama / weather_api
- 功能：LLM 自主调用天气/计算器/时间 3 个工具，支持多步规划
- 亮点：安全数学求值（AST 白名单）/ 缓存层 / 防御纵深

### 知识问答 RAG 系统
- 技术栈：Python / marker / BGE-Large-zh / BGE-Reranker-Large / Chroma / LangGraph
- 数据：4-5 万份内部文档（marker 批量处理，约 1 万份已完成）
- 实验：7 组对比实验，评测集 100 题，最优配置 Hit Rate 1.00 / MRR 0.881
- 亮点：评测集自动生成（LangGraph Agent）/ 多变量控制实验 / Reranker 精排
