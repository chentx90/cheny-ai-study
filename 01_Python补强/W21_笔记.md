### 1. 函数四种参数形态

> 位置参数-a-必填
> （默认参数 = 可变对象）-b=10-省略时为默认值
```python
def introduce(name, age=18, city="未知"):
    print(f"我叫{name}，今年{age}岁，来自{city}")
```
> 可变位置参数-*args-接受任意多位置参数得到元组
> 可变关键字参数-**kvargs-接收多个键值对得到字典
```python
def sum_numbers(*args):
sum_numbers(1, 2, 3)

def print_info(**kwargs):
print_info(name="张三", age=25)
```

### 2. LEGB 作用域规则

> L	Local	局部作用域	函数内部定义的变量
> E	Enclosing	嵌套作用域	外层嵌套函数的变量（闭包）
> G	Global	全局作用域	模块顶层定义的变量 
> B	Built-in	内置作用域	Python 内置的名称（如 print、len）
> 为什么 `x = x + 1` 在函数里会 UnboundLocalError
> 函数内部赋值的变量会被视为局部变量，除非使用global x来声明x是全局变量
