摘要

本文針對二氧化碳超臨界流體於天然物萃取之應用，研發一套具有多條通道及多種控制模式之電腦化綠色萃取分鎦控制系統，此控制系統之硬體部分主要為一個可進行氣液分離之旋風分離設備，而軟體部分則包含圖表編輯系統、參數設定系統與自動控制驅動器等三個模組單元。在進行綠色萃取過程中，系統所需控制的對象包括一組壓力、一組容積、

一組流量、一組溫度及八組開關程序，每一組控制對象皆須經由一個輸出入通道進行驅動

控制，且不同的控制對象有不同的控制模式需求（如壓力採用 PID 控制，容積與溫度採用增減 ON/OFF 控制，流量採用類比輸出控制，所有開關程序則皆為 ON/OFF 控制等）。本系統可依照設定的控制模式進行電腦化自動控制工作以完成天然物之萃取作業，本文並將示出應用本系統進行天然物萃取之實驗結果。

關鍵字：電腦化控制、控制模式、圖表編輯、超臨界萃取。

Abstract

This paper develops a computerized green extracting control system with multiple channels and multiple modes for CO2 supercritical extracting applications. The hardware part of this system is a gas-liquid spiral separating equipment, and the software part is composed of three modules: a chart-editing system, a parameter-setting system and an automatic control driver. In the supercritical extracting process, the controlled objects of this system includes one pressure device, one volume device, one flow device, one temperature device, and eight switching devices. Each controlled object is driven by one input-output channel, and different classes of objects need different control modes, such as PID control mode is used for pressure device, increment/ decrement ON/OFF control mode is used for volume and temperature devices, analog output control mode is used for flow device, and ON/OFF control mode is used for all switching devices. In this system, the green extracting task can be performed by automatic control process using preset control modes. And we shall show the results of extracting experiment performed by this system.

一、前言

超臨界流體(Supercritical Fluid)是指操

作溫度及壓力超過其臨界溫度及臨界壓力時

之流體[1,2]，超臨界流體已無液相與氣相共存時的明顯界面，其呈現一種流體之狀態，

甚至有些物質的顏色會由無色變成其它顏

色。超臨界流體一方面具有氣體的低黏度、

高擴張係數和低表面張力特性，另一方面則

具有液體的高密度與高溶解力特性，並且只

要調節其溫度和壓力即可增減對物質的溶解

能力[2,4]。

二氧化碳(CO2)超臨界流體因其臨界溫度低(約 31.3 ℃)，可減少對於熱敏感物質(如

酵素、天然蔬果、中草藥中機能性物質等)

的破壞，且臨界壓力低(約 72.9 atm)，容易使 CO2 達到超臨界狀態，再者其密度可隨溫度

及壓力而有所不同，易和其他固、液相的物

質分離，容易回收再使用；因此二氧化碳超

臨界流體已廣泛應用於各種天然物之萃取

[1,5,6,7]，例如由廢棄蕃茄皮中萃出蕃茄紅

素、由受損楊桃中萃出楊桃多酚、於廢棄柳

橙皮中萃出類黃酮、由茶梗中萃出茶多酚

等，之後再將萃取物進一步開發出相關應用

產品。

本文主要探討可進行各種天然物萃取的

電腦化二氧化碳超臨界流體萃取設備[3]之

研究開發，此萃取設備採取一種多條通道及

多種控制模式之數位控制系統[9,10,11]來進

行萃取作業，其中每一條通道皆有其特定控

制對象，而不同的控制對象則可具有不同的

控制模式。本系統進行綠色萃取所需控制的

對象包括一組壓力、一組容積、一組流量、

一組溫度及八組開關程序，每一組控制對象

皆須經由一個輸出入通道進行驅動控制，合

計使用 12 個控制通道。另外，不同的控制對

象有其不同的控制模式需求，如壓力採用

PID 控制，容積與溫度採用增減 ON/OFF 控

制，流量採用類比輸出控制，所有開關程序

則皆為 ON/OFF 控制等。以下我們將分別說

明此萃取控制系統之軟硬體設計、所採用之

控制模式、提供使用者操作之圖表編輯與參

數設定功能、以及其自動控制機制，最後我

們應用本系統由廢棄柳丁皮萃取類黃酮之實

驗，並進行實驗結果分析以驗證系統功能。

二、系統設計

本萃取控制系統是以 CO2為萃取物料之

助溶劑(cosolvent)，控制溫度(常溫)和壓力

(高壓)可使氣態 CO2 成為超臨界流體狀態， 藉由洩放壓力又可使 CO2 回復氣體狀態。由於 CO2 超臨界流體對有機物料具有極高的溶

解度，因此只要進行溫度、壓力、流量和容

積之適當控制，即可進行高級天然物(如茶多

酚、蕃茄紅素、類黃酮等)之高效率萃取作

業。

四、多重控制模式

為因應不同控制環境所存在的不同控制

需求，本系統中每一個通道皆有其特定採用

之控制模式，不同的控制模式需配合不同的

控制設備來執行其特有的操作，本控制系統

可執行工業上常用的四種控制模式之操作， 其控制設備之設計分述如下：

1. ON/OFF 控制模式：其控制設備如如圖

7(a) 所示，其中開關設備(switch device)

用來進行數位輸出之開關控制，依照控

制圖定義之工作曲線來決定開關動作， 當曲線電壓低於 2.5V 時做 OFF 輸出，而當電壓高於 2.5V 時執行 ON 輸出；此種

控制模式適用於操作控制閥開關之程序

控制。

2. 增減 ON/OFF 控制模式：其控制設備如

圖 7(b)所示，包含一個擷取設備(acquire

device) 、一組增加設備 (increment

device)、一組減少設備(decrement device)

及一個控制環境(control environment)。以

溫度之控制為例，擷取設備用來取得控

制環境(如高溫爐)中受控對象(溫度)之實

際值，將此回授之實際值與控制圖中定

義之目標值進行比對，當兩者之差超出

可容許之誤差範圍(亦稱比例帶)時，即需

調整控制環境，此時若實際值低於目標

值，則啟動增加溫度之設備(如加熱器)；

而若實際值高於目標值，則啟動減少溫

度之設備(如冷卻器)。

3. 類比輸出控制模式：其控制設備如圖 7(c)

所示，包含一組類比驅動設備 (analog

driven device)及一個控制環境。系統主要

依據控制圖中定義之工作曲線，直接輸

出類比訊號給類比驅動設備（如伺服馬

達或變頻馬達）來改變控制環境，但無

回授訊號之需求。

八、結論

本文主要探討可進行各種天然物萃取

的電腦化二氧化碳超臨界流體萃取設備之研

究開發，此萃取設備採取一種多條通道及多

種控制模式之數位控制系統來進行天然廢棄

物之萃取作業，其中每一條通道皆有其特定

控制對象，而不同的控制對象則可具有不同

的控制模式(例如壓力採用PID控制，容積與

溫度採用增減ON/OFF控制，流量採用類比

輸出控制，所有開關程序則皆為ON/OFF控

制等)。

在本系統中，使用者可透過編輯控制圖

與順序表來定義各控制對象之工作曲線，並

可藉由參數之設定來決定各通道自動控制之

運作方式，系統則依照預定的控制模式進行

電腦化自動控制工作以完成天然物之萃取作

業。最後，在本研究中我們應用此超臨界流

體萃取控制系統進行由廢棄柳丁皮萃取類黃

酮之實驗，透過控制圖設定不同的溫度工作

曲線與不同的壓力工作曲線，執行各種溫度

與壓力變化之萃取實驗，並進行溫度與壓力

交互關係之探討，分析萃取槽之總類黃酮以

求其最適操作條件。
