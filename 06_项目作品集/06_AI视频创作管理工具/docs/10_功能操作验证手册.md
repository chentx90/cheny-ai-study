# 功能操作验证手册

> 更新说明（2026-07-18）：本文中的 Nova 操作项已废弃。当前图片流程为“资源管理 → 实体清单 → 资产生成 → 项目素材/实体卡”，验收项见 `15_实体提取与资产生成重构计划.md`。

**版本**：2026-07-12  
**适用环境**：fnOS Docker（`http://<NAS-IP>:8010`）/ 本地开发（`8000` / `5173`）  
**用途**：按用户真实操作路径逐项验证功能是否可用；记录「预期 vs 实际」，便于定位逻辑问题与回归。

---

## 1. 使用说明

### 1.1 建议验证顺序

按创作主链路从前往后测，不要跳步：

```
初始化管理员 → 登录 → 创建项目 → 配置路径 → 预处理原文 → 分集/剧本
→ 资源/实体卡 → 设置 API → 提示词 → 生图(Nova) → 视频生成 → 导出/导入
```

### 1.2 记录方式

每个用例填写：

| 字段 | 说明 |
|------|------|
| **编号** | 如 `P-01`、`PRE-03` |
| **结果** | ✅ 通过 / ❌ 失败 / ⚠️ 与预期不符但可用 |
| **实际现象** | 失败时写清：不能输入、不能保存、保存后刷新丢失、无报错等 |
| **浏览器 Network** | 失败时记录请求 URL、HTTP 状态码、响应 `detail` |

### 1.3 通用前置

- [ ] 已用管理员账号登录（非访客）
- [ ] 侧栏底部服务状态正常（非长期「检查中」）
- [ ] 当前账户对测试项目为 **owner** 或 **editor**（viewer 会导致多处只读）
- [ ] 测试前在「项目管理」选中目标项目（多数业务页依赖「已选项目」）

## 2. 你已反馈问题的专项验证（优先做）

以下三项对应常见「逻辑问题」感受，请**单独先测**并记录。

### 2.1 新建项目时不能填路径

| 项 | 内容 |
|----|------|
| **编号** | P-PATH-01 |
| **操作** | 侧栏「项目管理」→ 新建项目 → 点 **更多选项** → 可填简介、数据目录、成片路径、素材路径 → **创建** |
| **当前产品设计** | 创建行默认只显示标题；展开「更多选项」后可填路径与简介 |
| **预期** | 创建成功；右侧「项目概览」出现该项目 |
| **后续应在哪里填** | 选中项目 → 项目概览 →「数据存储与导入导出」「项目默认设置」 |
| **易混淆** | 用户以为创建时应能填路径 → 实为**设计缺口**，非单次 bug |
| **改进期望（记录用）** | 创建向导中增加可选路径/简介，或创建后自动展开概览 |

### 2.2 后面填了路径「不能保存」

| 项 | 内容 |
|----|------|
| **编号** | P-PATH-02 |
| **操作** | 选中项目 → 项目概览 → 填写「项目数据目录」「成片输出位置」「原始素材导入位置」 |
| **当前产品设计** | 路径类字段修改后约 **350ms 自动保存**；也可点 **保存路径与默认设置** 立即保存并提示 |
| **验证保存是否成功** | ① 改完后等 1 秒；② **刷新浏览器**；③ 重新选中该项目，看字段是否仍在 |
| **预期** | 合法路径刷新后仍显示；非法 `data_root` 可能被后端拒绝或回退默认目录 |
| **失败典型原因** | ① 当前为 **viewer** 只读；② `data_root` 不在 workspace 内 → 400；③ 网络 403/401；④ 自动保存失败但仅顶部短暂提示，易忽略 |
| **Network 检查** | 改路径后应有 `PUT .../settings`，状态码 **200**；失败看 **400/403/423** |

**路径规则（测的时候对照）**

| 字段 | 规则 |
|------|------|
| `data_root`（项目数据目录） | 须在 workspace 内（容器内默认 `/data`） |
| `output_root`（成片输出） | 可 workspace 外绝对路径 |
| `source_assets_root`（原始素材） | 可 workspace 外；配合「刷新原始素材」扫描 |

### 2.3 原始内容不能输入 / 不显示文本

| 项 | 内容 |
|----|------|
| **编号** | PRE-DOC-01 |
| **操作** | 选中项目 → 侧栏「预处理」→ 左侧「原始内容」大文本框 |
| **预期** | 可点击输入；粘贴长文本；失焦后刷新页面内容仍在 |
| **失败典型原因** | 见下表 |

| 现象 | 可能原因 | 处理/记录 |
|------|----------|-----------|
| 整个预处理页灰掉、不能点 | 未选项目 | 先在项目管理选中项目 |
| 文本框不能输入 | 账户为 **viewer** 或该集被他人 **编辑锁** 占用 | 换 editor/owner；看橙色锁提示条 |
| 能输入但刷新后丢失 | 自动保存失败（401/403/423/409） | Network 看 `PUT .../document` |
| 一直空白 | 新项目尚未写入；或项目会话未加载 | 看 Network `GET .../session` 是否 200 |
| 「导入文档」无反应 | 未选项目；或文件格式不支持 | 用 `.txt` / `.md` / `.docx` 试 |

**持久化说明**：原文在 `onBlur`（光标离开文本框）时触发保存，不是每个按键都存。验证时请：**输入 → 点击页面空白处 → 等 1 秒 → 刷新**。

## 4. 端到端冒烟（一条线跑通）

适合发版前 30 分钟快测：

1. 登录 → 新建项目 `冒烟测试`
2. 概览填 `source_assets_root`（若有测试素材目录）并刷新素材
3. 预处理：粘贴 500 字测试文 → 章节切分 → 应用为分集 → 进入剧本 → 手改剧本并保存
4. 资源：上传 1 张图 → 建 1 张实体卡
5. 设置：LLM + 视频测试通过
6. 视频：生成提示词卡 → 提交 1 个视频任务（可看失败原因是否合理）
7. 导出 ZIP → 导入为新项目 → 新 ID 且 manifest 存在

## 5. 故障排查速查

| 症状 | 先查什么 |
|------|----------|
| 全局不能保存 | 是否登录过期（401）；是否 viewer（403） |
| 仅预处理不能改 | 分集锁（423）；`is-readonly` 样式 |
| 路径保存丢失 | `PUT /settings` 是否 200；`data_root` 是否非法 |
| 原文保存丢失 | 是否失焦；`PUT /document` 状态码 |
| 项目列表一直加载 | 后端/容器是否运行；`curl :8010/api/health` |
| 生图空白 | `docker compose ps` 中 nova 是否 Up；设置是否启用 Nova |
| 视频任务瞬间完成且是 txt | 视频通道是否为 mock/测试模式（记录 provider） |

**NAS 日志**

```bash
cd /vol1/docker/aivido
sudo docker compose logs ai-video-manager --tail=80
sudo docker compose logs nova --tail=80
```

## 6. 已知设计缺口汇总（验证时标 ⚠️ 即可）

| 缺口 | 影响 |
|------|------|
| 创建项目仅标题（默认） | 可展开「更多选项」填路径；概览仍可改 |
| 路径无显式保存按钮 | 已增加「保存路径与默认设置」+ 自动保存 |
| 原文 textarea 曾无法输入 | 已修复：`updateWorkspace` 直接更新，不再经错误 `setWorkspace` 包装 |
| 分集锁误锁原文区 | 已修复：原文区与分集/剧本区只读分离 |
| 视频页不继承分集只读锁 | 预处理只读时视频页仍可能可改 |
| 无「资产已确认」按钮 | 工作流 `assets_confirmed` 难推进 |
| 实体智能绑定等仅 API | UI 无入口 |
| `defaultVideoDuration` 无 UI | 只能在视频流程或 API 侧体现 |
