# 实体提取与资产生成重构计划

> 状态：执行中  
> 日期：2026-07-18  
> 上位契约：`12_V2大重构实施计划.md`、`13_V2领域与API契约.md`  
> 原则：实体分析与实体卡分层；图片生成原生整合；业务提示词只来自提示词管理。

## 1. 目标

将现有“单段剧本临时提取 JSON + 人工创建实体卡 + Nova 外挂生图”替换为项目内正式生产链：

```text
Episode.script_text
  -> 按集 LLM 提取实体及证据
  -> 跨集聚合别名、状态和统计
  -> EntityProfile / EntityVariant 人工审核
  -> 生成设定
  -> 生成资产提示词
  -> ImageGenerationTask / ImageOutput
  -> ProjectAsset
  -> EntityCard
```

## 2. 产品边界

1. 默认分析项目全部已入库剧本，也允许指定分集；只处理 `script_text`，不读取原文代替剧本。
2. LLM 负责识别实体、别名、证据、角色定位和状态候选；后端根据证据确定性计算提及次数、出现集和首次/最后出现。
3. 人工修改的名称、类型、重要性、设定和状态不得被后续分析静默覆盖。
4. `EntityProfile` 是分析与审核对象；`EntityCard` 是视频生产使用的稳定资产对象，两者不是同一层。
5. 项目允许多个视觉风格方案，同时只有一个活动版本；任务保存风格快照，历史结果不随风格编辑变化。
6. 人物、场景、物品分别保存图片模型、尺寸、比例、默认视图、生成数量及专用正负向提示词。
7. 图片成功结果立即进入项目素材库，采用到实体卡默认人工确认；快速模式允许自动创建卡并采用首张成功结果。
8. 批量生成默认只选择 S/A/B 级实体，实际执行范围由用户勾选和二次确认决定。
9. 文件只保存一次，实体卡及候选输出只引用 `ProjectAsset`。

## 3. 领域模型

| 模型 | 责任 |
|---|---|
| `EntityExtractionRun` | 一次跨集实体分析，保存分集 revision 快照和状态 |
| `EntityMention` | 某实体在某集的证据片段、别名、出现次数 |
| `EntityProfile` | 跨集规范实体、角色定位、重要性、统计、设定及审核状态 |
| `EntityVariant` | 实体在年龄、服装、时段、天气或损坏状态下的视觉变体 |
| `ProjectVisualStyle` | 项目统一视觉风格版本及参考素材 |
| `AssetGenerationPreset` | character / scene / prop 三类独立生成参数 |
| `EntityAssetPrompt` | 提示词生成结果及模板、风格、档案版本快照 |
| `ImageGenerationTask` | 一次不可变图片生成请求和执行状态 |
| `ImageOutput` | 图片候选结果，引用唯一 `ProjectAsset`，记录采用状态 |

## 4. 提示词模板

正式链只消费提示词管理中的以下类别，不允许代码内嵌备用正文：

```text
entity_extract
entity_consolidate
entity_setting
character_asset_prompt
scene_asset_prompt
prop_asset_prompt
```

模板变量：

| 变量 | 用途 |
|---|---|
| `$episode_title` | 当前分集标题 |
| `$episode_script` | 当前分集完整剧本 |
| `$episode_order` | 当前分集序号 |
| `$extraction_catalog` | 按集提取结果，供跨集聚合 |
| `$entity_profile` | 当前实体档案 JSON |
| `$entity_name` | 规范实体名称 |
| `$entity_setting` | 已审核设定 |
| `$variant_setting` | 当前状态变体 |
| `$project_style_prompt` | 项目统一正向风格 |
| `$project_negative_prompt` | 项目统一负向风格 |
| `$type_prompt` | 类型专用正向约束 |
| `$type_negative_prompt` | 类型专用负向约束 |
| `$reference_summary` | 已有关联素材摘要 |
| `$view_type` | 头像、全身、三视图、远景、单体等视图 |

## 5. 页面结构

资源管理固定为四个标签：

```text
实体清单 | 实体卡库 | 资产生成 | 项目素材
```

- 实体清单：范围选择、运行分析、统计筛选、证据查看、人工审核、设定生成、快速入库。
- 实体卡库：继续承担视频引用实体和小素材库维护。
- 资产生成：项目风格、三类预设、待生成实体、提示词审核、任务及候选采用。
- 项目素材：继续使用已有上传、分类、筛选、重命名、预览和删除能力。
- 独立“生图”导航、Nova iframe 和 Nova 配置全部删除。

## 8. 完成定义

1. 有剧本的新项目可在资源管理中一次运行形成跨集实体清单。
2. 清单可解释：每项能查看证据、次数、出现集、重要性和人工覆盖状态。
3. 人物、场景、物品使用统一项目风格但保留独立生成参数。
4. 生成提示词与生成图片可分别保存、编辑、重跑和追溯。
5. 图片成功后只产生一份项目素材，采用后实体卡建立引用。
6. 刷新不丢项目、资源标签、风格或预设；项目之间无数据串用。
7. 代码和部署中不再存在 Nova 运行依赖和用户入口。
