## 技术栈选型

### 前端技术栈
**框架**: React 18+ / Vue 3+（推荐React）
- **状态管理**: Zustand / Redux Toolkit
- **UI组件库**: Ant Design / Material-UI
- **样式方案**: TailwindCSS + CSS Modules
- **路由**: React Router v6
- **数据请求**: TanStack Query (React Query)
- **表单管理**: React Hook Form + Zod验证

**理由**:
- React生态成熟，组件复用性强
- Zustand轻量级状态管理，适合中小型项目
- TailwindCSS快速开发，Ant Design提供企业级组件

### 后端技术栈
**语言**: Python 3.11+ / Node.js 18+（推荐Python）
- **Web框架**: FastAPI / Flask
- **异步处理**: asyncio + aiohttp
- **任务队列**: Celery + Redis / Bull (Node.js)
- **数据库**: SQLite（本地） + SQLAlchemy ORM
- **文件处理**: python-docx, PyPDF2, markdown-it
- **AI集成**: OpenAI SDK, Anthropic SDK, LangChain

**理由**:
- Python在AI/NLP领域工具链完善
- FastAPI高性能异步支持，自动生成API文档
- SQLite零配置，适合本地部署

### DevOps工具链
- **版本控制**: Git + GitHub/GitLab
- **包管理**: Poetry (Python) / pnpm (Node.js)
- **容器化**: Docker + Docker Compose
- **测试框架**: Pytest + pytest-bdd (Python) / Jest + Cucumber (Node.js)
- **代码质量**: Ruff + mypy (Python) / ESLint + Prettier (Node.js)
- **CI/CD**: GitHub Actions / GitLab CI

#### 关键算法
**智能预绑定（模糊匹配）**:
```python
def fuzzy_match_entities(
    extracted: Entity, 
    library: List[EntityCard]
) -> List[Tuple[EntityCard, float]]:
    """
    1. 文本相似度：编辑距离 + 语义向量相似度
    2. 标签匹配：共同标签数量/总标签数
    3. 上下文相关性：在同一剧本中出现的实体
    4. 综合评分排序，返回Top-K候选
    """
    scores = []
    for card in library:
        text_sim = calculate_text_similarity(extracted.name, card.entity_name)
        tag_sim = calculate_tag_overlap(extracted.tags, card.tags)
        context_sim = calculate_context_relevance(extracted, card)
        
        final_score = 0.5 * text_sim + 0.3 * tag_sim + 0.2 * context_sim
        scores.append((card, final_score))
    
    return sorted(scores, key=lambda x: x[1], reverse=True)[:5]
```

```python
from enum import Enum
from transitions import Machine

class WorkflowState(Enum):
    INITIALIZED = "initialized"
    DOCUMENT_SPLIT = "document_split"
    SCRIPT_CONVERTED = "script_converted"
    ENTITIES_EXTRACTED = "entities_extracted"
    ENTITIES_BOUND = "entities_bound"
    PROMPTS_GENERATED = "prompts_generated"
    ASSETS_CONFIRMED = "assets_confirmed"
    VIDEO_GENERATING = "video_generating"
    VIDEO_COMPLETED = "video_completed"

class WorkflowEngine:
    """工作流编排引擎"""
    states = [s.value for s in WorkflowState]
    
    transitions = [
        {'trigger': 'split', 'source': 'initialized', 'dest': 'document_split'},
        {'trigger': 'convert', 'source': 'document_split', 'dest': 'script_converted'},
        {'trigger': 'extract', 'source': 'script_converted', 'dest': 'entities_extracted'},
        # ... 更多转换规则
    ]
    
    def __init__(self, project: Project):
        self.project = project
        self.machine = Machine(
            model=self, 
            states=WorkflowEngine.states,
            transitions=WorkflowEngine.transitions,
            initial=project.current_state
        )
    
    def can_jump_to(self, target_state: WorkflowState) -> bool:
        """检查是否可以跳转到目标状态（前置信息是否足够）"""
        pass
```

## 数据存储设计

### 数据库Schema

```sql
-- 项目表
CREATE TABLE projects (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    current_state TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 文档表
CREATE TABLE documents (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    filename TEXT NOT NULL,
    format TEXT NOT NULL,
    content TEXT,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);

-- 剧本片段表
CREATE TABLE script_segments (
    id TEXT PRIMARY KEY,
    document_id TEXT NOT NULL,
    order_index INTEGER NOT NULL,
    content TEXT NOT NULL,
    is_converted BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (document_id) REFERENCES documents(id)
);

-- 实体卡片表
CREATE TABLE entity_cards (
    id TEXT PRIMARY KEY,
    entity_name TEXT NOT NULL,
    state TEXT,
    tags TEXT,  -- JSON array
    reference_images TEXT,  -- JSON array
    audio_samples TEXT,
    video_clips TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 实体绑定表
CREATE TABLE entity_bindings (
    id TEXT PRIMARY KEY,
    segment_id TEXT NOT NULL,
    entity_name TEXT NOT NULL,
    card_id TEXT,
    confidence REAL,
    confirmed BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (segment_id) REFERENCES script_segments(id),
    FOREIGN KEY (card_id) REFERENCES entity_cards(id)
);

-- 提示词模板表
CREATE TABLE prompt_templates (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    category TEXT NOT NULL,
    template TEXT NOT NULL,
    variables TEXT,  -- JSON array
    is_default BOOLEAN DEFAULT FALSE
);

-- 视频任务表
CREATE TABLE video_tasks (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    segment_id TEXT NOT NULL,
    prompt TEXT NOT NULL,
    assets TEXT,  -- JSON object
    status TEXT NOT NULL,  -- pending, processing, completed, failed
    result_path TEXT,
    api_task_id TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(id),
    FOREIGN KEY (segment_id) REFERENCES script_segments(id)
);

-- 版本表
CREATE TABLE versions (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    version_number TEXT NOT NULL,
    stage TEXT NOT NULL,
    snapshot TEXT NOT NULL,  -- JSON
    metadata TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(id)
);

-- 检查点表
CREATE TABLE checkpoints (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL,
    state TEXT NOT NULL,
    data TEXT NOT NULL,  -- JSON
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(id)
```

## 性能优化策略

### 1. 缓存策略
- **实体库缓存**: Redis/内存缓存，减少磁盘IO
- **提示词模板缓存**: 启动时预加载到内存
- **AI响应缓存**: 相同输入缓存LLM响应结果

### 2. 异步处理
- 文档切分、实体提取等耗时操作使用异步任务队列
- 视频生成使用后台任务+轮询机制
- WebSocket实时推送任务进度

### 3. 批量操作优化
- 批量数据库写入使用事务
- 批量API调用使用连接池
- 批量文件操作使用多线程/协程

### 4. 懒加载
- 大文件分段加载
- 实体库按需加载
- 视频预览缩略图延迟加载
